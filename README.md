# Private Chat Documentation

私聊系统的架构迁移、开发任务和版本记录仓库。

## 文档索引

- `development-tasks.md`：开发任务与实施状态。
- `private-server-migration.md`：私有服务端迁移方案。
- `版本记录.md`：版本变更记录。

修改方案时应同步更新任务状态和版本记录，涉及服务地址、密钥、账号或生产拓扑的内容应使用脱敏示例，不在文档中保存真实凭据。

## 文档描述的实现

迁移文档围绕私聊系统从旧服务向独立私有服务端迁移，记录组件边界、数据迁移、兼容切换和回滚条件；开发任务文档把服务端、桌面端、Android、iOS 及联调事项拆成可验收步骤；版本记录保存已落地能力和行为变化。实施时应以任务清单作为执行状态，以迁移文档作为架构约束，以版本记录作为最终事实，三者在每次发布后同步更新。
